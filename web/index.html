        Setup

        Checking for the music reading program…

        score2audio uses the free program Audiveris to read music from PDF files. To install it:

        1. Open the Audiveris downloads page (opens in a new tab).
        2. Under the newest release, download the file ending in windowsConsole-x86_64.msi, and run it.
        3. Under the newest release, download the file ending in macosx-arm64.dmg for a Mac with Apple silicon (M1 or newer), or macosx-x86_64.dmg for an Intel Mac. Open it and drag Audiveris to your Applications folder.
        4. Install Audiveris from your distribution (for example the audiveris package in the Arch User Repository), from Flathub, or from the .deb file on the downloads page for Debian and Ubuntu.
        5. Come back to this page and press the Check again button.

        MusicXML files can be opened without Audiveris.

        For example: C:\Program Files\Audiveris

        score2audio runs only on this computer. Your scores are not sent anywhere.

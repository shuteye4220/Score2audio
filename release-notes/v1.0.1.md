A fix for the Android app, which could not open score files.

**Android users:** install `score2audio-android.apk` from this release over version 1.0.0; your scores and settings are kept. Then add the `.s2a` files that were refused; they work as they are, with no need to export them again.

### Fixed
- The Android app said "That is not a score2audio score file" for every score file. Score files are zip files, and the app read them in a way that cannot handle how score2audio 1.0.0 stored the music inside them. The app now reads them through the zip's table of contents, which works for score files from every version.
- When a file really cannot be opened, the app now says why.

### Changed
- The computer program writes score files in the most widely readable zip layout, with the score itself first.
- The app's handling of score files is covered by automated tests, including a file laid out exactly as 1.0.0 exported them.

### Security and efficiency
- The app only unpacks the score itself from a score file, not the music files alongside it.
- A crafted score file can no longer make the app reserve a large block of memory up front, and score data larger than a notetaker can comfortably handle is refused with a message instead of crashing the app.
- Temporary copies left behind if the app is closed while adding a score are cleaned up.

### Downloads
- Windows: `score2audio-windows.zip`
- Mac (Apple silicon and Intel): `score2audio-mac.zip`
- Linux: `score2audio-linux-x86_64.tar.gz`
- Android (10 or newer): `score2audio-android.apk`

See the README for installation instructions.

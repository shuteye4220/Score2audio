The first release of score2audio, with a security and efficiency update. Everyone using a test build should update.

**Android users:** if you installed a test version of the app (from the builds branch or a build artifact), uninstall it first, then install `score2audio-android.apk` from this release. The app is now signed with the project's own private key, so Android will not install it over the old test versions. Uninstalling removes the scores stored in the app, so add your `.s2a` files again afterwards. Future updates will install over this version as normal.

### Security
- Built with Go 1.27. The Go 1.24 used for the test builds is out of support and has 22 known vulnerabilities on code paths score2audio uses, including one where a deeply nested MusicXML file could crash it.
- Compressed MusicXML (`.mxl`) and score files (`.s2a`) can no longer unpack to gigabytes of data ("zip bombs") and exhaust your computer's memory.
- Music from PDFs, MusicXML and shared score files is checked before it is stored or played, on the computer and on Android, so a damaged or crafted file cannot freeze or crash the player or fill your storage.
- The Android app is signed with a private key; the old signing key was public.
- Your score library is only readable by your own user account.
- The bundled lyrics-reading data is pinned to a known version and checked before packaging.

### Faster
- Lyrics are matched to the music much faster on long scores, and following the current measure while playing takes less work, on the computer and on Android.

### Downloads

- Mac (Apple silicon and Intel): `score2audio-mac.zip`
- Linux: `score2audio-linux-x86_64.tar.gz`
